# java-lotto-precourse

# 요구사항

- else 예약어를 사용하지 않는다. return을 활용.
- ENUM을 적용하여 구현한다
# 구현 목록


## 입력

- [ ] 구입 금액을 입력받는다
- [ ] 입력받은 금액을 통해 로또 구앱 개수를 반환한다
- [ ] 당첨 번호 6개를 쉼표 기준으로 입력받는다
- [ ] 쉼표를 기준으로 나눠진 값을 List로 반환한다
- [ ] 보너스 번호를 입력받는다

예외
- [ ] 잘못된 입력시, "ERROR" 출력하고 그 부분부터 다시 입력받는다

## 실행

### `Lotto.class`
- [ ] 당첨 번호를 입력받는다
- [ ] 객체 생성시 랜덤값 6개를 numbers에 저장한다.

### `Lottos.class`
- [ ] 로또 수량 저장
- [ ] `List<Lotto>`를 가진다
- [ ] 각 로또번호를 오름차순 정렬한다
- [ ] 각 로또의 당첨 여부를 판단한다
- [ ] 각 등수의 당첨횟수를 저장하고, 반환한다
    

### `Calculate.class`
- [ ] 수익률을 계산한다

### `Win.class`
- [ ] 당첨번호를 가진  enum(`WINNINGNUMBER`)이 있다



## 출력

- [ ] 발행한 로또 수량을 출력한다
- [ ] 각 로또 번호를 출력한다

- [ ] 당첨 내역을 출력한다
- [ ] 수익률을 출력한다 (소수점 둘째 자리에서 반올림)
