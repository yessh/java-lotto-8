# java-lotto-precourse

# 구현 목록


## 입력

- [x] 구입 금액을 입력받는다
- [x] 구매 금액의 유효성을 검사한다 (1000원 단위, 숫자, 0 이상)
- [x] 당첨 번호 6개를 쉼표 기준으로 입력받는다
- [x] 쉼표 기준으로 나눠진 값의 유효성을 검사하고 객체(Lotto)로 반환한다
- [x] 보너스 번호를 입력받는다
- [x] 보너스 번호의 유효성을 검사한다 (1~45 범위, 숫자, 당첨 번호와 중복 불가)
- [x] 입력받은 금액을 통해 로또 구매 개수를 반환한다

예외
- [x] 잘못된 값 입력시, `[ERROR]`를 출력하고 다시 입력받는다

## 실행

- [x] 로또 수량(count)만큼 로또(Lotto) 객체를 생성한다
- [x] 각 로또 객체 생성 시 1~45 범위의 중복되지 않는 랜덤 숫자 6개를 가진다
- [x] 생성된 로또 번호는 오름차순으로 정렬한다
- [x] 구매한 로또들을 List<Lotto>로 감싼 일급 컬렉션(Lottos)으로 관리한다
- [x] 당첨 번호 6개와 보너스 번호 1개를 WinningLotto 객체로 관리한다
- [x] (Enum 적용) 당첨 등수들과 상금 정보를 Rank Enum으로 관리한다
- [x] 각 로또가 WinningLotto와 비교하여 자신의 등수(Rank)를 반환한다
- [x] 모든 로또의 당첨 통계를 Statistics 객체로 계산한다
- [x] 각 등수의 당첨 횟수를 Map<Rank, Integer> 형태로 저장한다
- [x] 총 수익률을 계산한다



## 출력

- [x] 발행한 로또 수량(N개)을 출력한다
- [x] 발행한 모든 로또의 번호를 형식에 맞게 출력한다
- [x] 당첨 내역(통계)을 형식에 맞게 출력한다
- [x] 수익률을 소수점 둘째 자리에서 반올림하여(첫째 자리까지) 출력한다
